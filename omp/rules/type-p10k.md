# P10k Entry Type

Powerlevel10k (p10k) entries define the appearance and behavior of the Zsh prompt. They control prompt segments (directory, git status, execution time, etc.), icons, colors, and instant-prompt behavior.

P10k config is deployed by `carrel os-setup` (container) or `carrel host-setup` (host). Despite being Zsh syntax, p10k entries are a separate carrel type because they have distinct deployment and validation semantics.

## Format

- **File extension:** `.zsh`
- **Location:** `omp/config/zsh/<name>.zsh` (typically `p10k.zsh`)
- **Frontmatter:** None. P10k files are Zsh scripts that set `POWERLEVEL9K_*` variables.
- **Generation:** The canonical p10k configuration is generated by running `p10k configure` interactively. Carrel stores the generated file.

## Naming Conventions

- **`p10k.zsh`** is the standard entry point — it's sourced by `zshrc.zsh`
- **Additional p10k files** use the `p10k-` prefix: `p10k-custom-segments.zsh`, `p10k-transient-prompt.zsh`
- **Avoid generic names:** `theme.zsh`, `prompt.zsh`

## Content Best Practices

- **Generated, then curated.** Start with the output of `p10k configure`, then hand-edit for carrel-specific needs. The generated file is verbose — comments are useful documentation, don't strip them.
- **Instant prompt comes first.** The instant-prompt section MUST be near the top of `zshrc.zsh`, before anything that might delay shell startup:
  ```zsh
  if [[ -r "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh" ]]; then
    source "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh"
  fi
  ```
- **All variables use `POWERLEVEL9K_` prefix.** Every p10k setting is a Zsh variable in this namespace:
  ```zsh
  POWERLEVEL9K_MODE='nerdfont-complete'
  POWERLEVEL9K_LEFT_PROMPT_ELEMENTS=(dir vcs)
  POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS=(status command_execution_time)
  ```
- **Prompt elements in order.** `POWERLEVEL9K_LEFT_PROMPT_ELEMENTS` and `POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS` define segment ordering. List segments left-to-right as they should appear.
- **Transient prompt for clean history.** Enable transient prompt so previous commands show a minimal prompt — saves vertical space in scrollback:
  ```zsh
  POWERLEVEL9K_TRANSIENT_PROMPT=always
  ```
- **Configuration wizard settings.** When customizing, reference the p10k configuration wizard's segment documentation. Each segment has specific `POWERLEVEL9K_<SEGMENT>_*` variables.
- **Custom segments.** Define custom prompt segments in separate files and source them:
  ```zsh
  function prompt_my_custom() {
    p10k segment -t 'custom text'
  }
  ```
- **Font compatibility.** If using Nerd Font icons, ensure `POWERLEVEL9K_MODE` matches the installed font. Common modes: `nerdfont-complete`, `nerdfont-v3`.
- **Test with `p10k display`.** After changes, run `p10k display` to preview the updated prompt without restarting the shell.

## Deployment Behavior

1. **Registration:** `carrel config add p10k <name> --file=omp/config/zsh/<name>.zsh`
2. **Slot wiring:** `carrel slot sync-all`
3. **Deployment:**
   - Container: `carrel os-setup` deploys to the container's `$ZDOTDIR`
   - Host: `carrel host-setup` deploys to the host's `$ZDOTDIR`
4. **Loading:** Zsh sources `p10k.zsh` as part of the shell startup sequence (typically from `zshrc.zsh`). Instant prompt activates before the full p10k config loads for minimal startup latency.

P10k config is NOT deployed by `carrel run`.

## Validation

Use the `validate-p10k` skill to check:
- File has `.zsh` extension
- Syntax is valid Zsh (`zsh -n <file>` passes)
- All configuration variables use the `POWERLEVEL9K_` prefix
- `POWERLEVEL9K_LEFT_PROMPT_ELEMENTS` and `POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS` are defined
- Referenced segments are valid p10k segment names
- Instant-prompt setup is present in `zshrc.zsh` (not in the p10k file itself)
- File is at the correct path under `omp/config/zsh/`

## Example

```zsh
# Powerlevel10k configuration generated by p10k configure, then curated.
# Font: MesloLGS NF (Nerd Font complete)

POWERLEVEL9K_MODE='nerdfont-complete'

# Left prompt: directory + git status
POWERLEVEL9K_LEFT_PROMPT_ELEMENTS=(dir vcs)

# Right prompt: last command status + execution time
POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS=(status command_execution_time)

# Directory segment
POWERLEVEL9K_DIR_FOREGROUND='blue'
POWERLEVEL9K_SHORTEN_STRATEGY='truncate_to_unique'
POWERLEVEL9K_SHORTEN_DIR_LENGTH=3

# Git segment
POWERLEVEL9K_VCS_BRANCH_ICON='\uF126 '

# Transient prompt — show only '❯' for previous commands
POWERLEVEL9K_TRANSIENT_PROMPT=always

# Instant prompt (configured in zshrc.zsh, not here)
```
