# Validate P10k

Validate a Powerlevel10k configuration entry for structural correctness
and completeness. Works for pre-registration checks (before
`carrel config add`) and post-hoc audits of already-registered p10k
config files.

## What to Validate

### Content structure

- The file is valid zsh script compatible with Powerlevel10k's
  instant prompt and configuration protocol.
- The file is generated by `p10k configure` or follows the p10k config
  format exactly.
- The `POWERLEVEL9K_MODE` variable is set to a valid value (e.g.,
  `nerdfont-complete`).
- Segment configuration follows the `POWERLEVEL9K_<SEGMENT>_*` naming
  pattern.
- Left and right prompt segments are defined with
  `POWERLEVEL9K_LEFT_PROMPT_ELEMENTS` and
  `POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS`.
- Instant prompt is configured (`POWERLEVEL9K_INSTANT_PROMPT`).

### Naming conventions

- The entry name is kebab-case.
- The filename uses lowercase with hyphens and a `.zsh` extension.
- Common name: `p10k.zsh`.

### Cross-references

- The p10k config references valid Powerlevel10k segment names.
- If the config customizes git or other tool segments, those tools are
  available.
- The config does not conflict with other zsh entries sourced in the
  same shell session.

## How to Validate

### Pre-registration (new p10k config)

1. Verify the file is at `omp/config/zsh/<name>.zsh` or the
   target-specific equivalent.
2. Check that the filename uses kebab-case and the `.zsh` extension.
3. Run `zsh -n <file>` to validate shell syntax.
4. Confirm `POWERLEVEL9K_MODE` is set.
5. Verify left and right prompt element arrays are defined and
   reference valid segment names.
6. Check that all segment customization variables use correct
   `POWERLEVEL9K_` prefixing.

### Post-hoc audit (existing p10k config)

1. Run `carrel config view p10k <name> --meta-only` and confirm
   registration.
2. Run `carrel trace <source>:p10k:<name>` to verify deployment.
3. Compare on-disk hash with the registry hash.
4. Run `zsh -n` on the deployed file to confirm syntax.
5. Verify segment references are still valid against the installed
   Powerlevel10k version.
